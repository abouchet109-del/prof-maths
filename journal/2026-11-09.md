- Q1 Une intersection infinie d'ouverts est-elle ouverte ? Exemple ? → non en général ; vrai pour une intersection finie ; exemple ∩_n ]−1/n, 1/n[ = {0} (fermé, pas ouvert) ou {a} = ∩_{b≠a}(X∖{b}) ; une réunion quelconque d'ouverts est ouverte. Dans ex05 Q3, A = ∩_{a∈X∖A}(X∖{a}) est seulement « une intersection d'ouverts », pas un ouvert.
- Q2 g(t) = max(0, t − 1/2) sur [0,1] : trouver f continue, non nulle, avec fg = 0 ; que vaut N(f) ; quel axiome échoue ? → f(t) = max(0, 1/2 − t) (nulle sur [1/2,1], non nulle sur [0,1/2[) ; fg = 0 donc N(f) = ‖fg‖∞ = 0 avec f ≠ 0 : la séparation échoue. Cas général : {g≠0} non dense ⇒ il existe un intervalle ]a,b[ avec g = 0 dessus ⇒ f(t) = max(0, min(t−a, b−t)) (« chapeau ») est continue, non nulle, fg = 0.
### Réponses et notes

- Q2 : partiel.
